What “local” means at SJSUHack: Your project’s AI inference must run on the event’s ZGX Nano — not on personal laptops or cloud AI APIs. Hybrid setups are allowed. You’re completely free to use cloud tools for non-AI work like Google Slides, Canva, Figma, Loom, or YouTube for your presentation and video.

What's Allowed

✅ You Can Use

  • The event’s ZGX Nano for all AI inference
  • Open-source models (Llama, Mistral, Phi, Gemma, etc.) — run on the ZGX Nano
  • Hybrid setups using the ZGX Nano as your AI backend
  • Open-source libraries and frameworks
  • Hugging Face model hub (downloaded & run on ZGX Nano)
  • HP developer tools, APIs, and on-site hardware
  • Public datasets and open APIs (non-AI)
  • UI component libraries and frontend tools
  • Cloud tools for slides, video & design (Google Slides, Canva, Loom, Figma, etc.)
  • Personal GitHub repos as reference (not as your submission)
What's Not Allowed

❌ You Cannot

  • Run AI inference on your personal laptop or personal machine
  • Use cloud AI APIs (OpenAI, Gemini, Anthropic, etc.) as your project’s core AI inference
  • Use paid cloud GPU services for AI (AWS SageMaker, GCP Vertex, Azure ML)
  • Start coding before hacking begins
  • Submit a project built before the event
  • Use plagiarized code or violate open-source licenses
  • Submit work to multiple tracks (pick one!)
  • Use copyrighted content without permission
