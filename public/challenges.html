What's Allowed

✅ You Can Use

  • Local open-source models (Llama, Mistral, Phi, Gemma, etc.)
  • The event's shared GPU cluster for inference
  • Open-source libraries and frameworks
  • Hugging Face model hub (local download & run)
  • HP developer tools, APIs, and on-site hardware
  • Public datasets and open APIs (non-AI)
  • UI component libraries and frontend tools
  • Personal GitHub repos as reference (not as your submission)
What's Not Allowed

❌ You Cannot

  • Rely solely on cloud AI APIs (OpenAI, Gemini, Anthropic, etc.) as your core inference
  • Use paid cloud GPU services (AWS SageMaker, GCP Vertex, Azure ML)
  • Start coding before hacking begins
  • Submit a project built before the event
  • Use plagiarized code or violate open-source licenses
  • Submit work to multiple tracks (pick one!)
  • Use copyrighted content without permission
What to Submit

Submission Requirements

Every team must submit all three deliverables before the hacking deadline on Sept 26th.

🗂️

Git Repository

Public GitHub or GitLab repo with all source code, a clear README, setup instructions, and a description of how local/hybrid inference is implemented.

✓ Public repo ✓ README with setup steps ✓ Commit history required
📊

Slide Deck

A presentation covering your problem statement, solution, tech stack, local/hybrid architecture, and the impact of your project. Keep it concise and clear.

✓ PDF or Google Slides link ✓ Problem → Solution → Impact ✓ Architecture diagram included
🎬

2-Min Demo Video

A screen-recorded or in-person demo of your working project. Show the core feature, the local AI model running, and your team briefly introducing the solution. Max 2 minutes.

✓ Max 2 minutes ✓ YouTube / Drive / Loom link ✓ Must show live demo
⏰

Submission deadline: Sept 26, 2026 — 10:00 PM. All three deliverables must be submitted via the registration form before hacking ends. Late submissions will not be accepted.
