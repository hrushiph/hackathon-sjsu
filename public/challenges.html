Judging Criteria

All projects are evaluated across four core dimensions. Track-specific rubrics may add additional criteria.

💡

Innovation

25%

Novelty, creativity, and originality of the idea and execution.

⚙️

Technical Depth

25%

Complexity, quality of code, and appropriate use of technology.

🌍

Impact

25%

Real-world feasibility, potential impact, and scalability.

🎤

Presentation

25%

Clarity of pitch, quality of demo, and ability to answer questions.

What's Allowed

✅ You Can Use

  • Open-source libraries and frameworks
  • Public APIs and datasets
  • AI APIs (OpenAI, Gemini, Hugging Face, etc.)
  • Cloud services (GCP, AWS, Azure)
  • HP developer tools and APIs
  • UI component libraries
  • Personal portfolio / GitHub repos as reference
What's Not Allowed

❌ You Cannot

  • Start coding before hacking begins
  • Submit a project built before the event
  • Use plagiarized code or violate licenses
  • Submit work to multiple tracks (pick one!)
  • Use copyrighted content without permission
